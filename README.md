# Dave's & Enemies

A 2D action adventure about Dave, a knight searching for the stolen Holy Grail.
Explore the desert, fight enemies, find supplies and treasure, and face the Pharaoh.

The game is still in development. The current chapter has three connected desert
areas with side paths, hidden caches, checkpoints, and a boss fight.

## Built with

- **GameMaker LTS 2026** and **GML** for the game.
- **JSON** for maps, dialogue, items, and enemy data.
- **Python**, **Pillow**, **NumPy**, and **SciPy** for asset and map tools.
- **Git and GitHub** for version control.

## Run the project

Open `Dave's & Enemies.yyp` in GameMaker LTS 2026 and press **F5**.
The current build targets Windows. Python is only needed for the supporting tools.
